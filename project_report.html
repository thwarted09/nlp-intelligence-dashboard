1. Executive Summary

Project Objective: Build a dedicated intelligence perception testing workspace that ingests raw dispatches, intercepted feeds, and news data collected in MongoDB. The platform provides interactive data slicing, multi-stage NLP pipeline creation, live streaming execution logs, perception scoring, and human validation.

During Phase 1, the entire frontend workspace was designed, implemented, compiled, and verified on Windows with zero build or runtime errors. In addition, an API contract and a complete starter backend implementation using Python FastAPI and PyMongo was delivered with MongoDB database seeding utilities.

2. Completed Feature Inventory

🗄️ 1. Dataset & Collection Ingestion
  • MongoDB Collections Switcher: Direct switching between preloaded intelligence collections (Geopolitics, Tech Perception, Threat Streams, Crisis Response).
  • Test Partition Sampling: 1-click test sampling presets (5, 10, 25, 50, 100 documents) or custom slice limit to extract a working partition from MongoDB (avoiding dumping the entire database at once).
  • Selective Document Staging for NLP: Interactive checkboxes and staging deck allowing analysts to cherry-pick exactly which records are taken forward for the NLP activity (rather than blindly processing the whole collection).
  • Sampling Methods: Random Uniform (MongoDB $sample), Sequential (First N), and Most Recent First.
  • Search & Source Filters: Filter by keyword or source type (News, Telegram, Social, Forum, Diplomatic Wire).
  • BSON/JSON Inspector: Full modal displaying raw MongoDB representation with ObjectId, ISODate, and 1-click clipboard copy.
⚙️ 2. Modular NLP Pipeline Builder
  • 8 Predefined NLP Tasks: NER, Perception Polarity, Stance Alignment, Emotion Profiling, Narrative Tagging, Keyphrases, Summaries, Integrity Screening.
  • Interactive Architecture Flowchart: Visual flow graph displaying data passing through each stage to final output.
  • Execution Reordering: Move stages up/down, toggle active/inactive with one click.
  • Hyper-parameter Tuner: Modal slider controls for confidence thresholds, model runtimes, and summary formats.
  • Workflow Presets: Pre-configured suites including Full OSINT Suite, Rapid Screener, Threat Triage, and Executive Briefer.
⚡ 3. Job Execution & Streaming Console
  • Live Telemetry: Real-time progress bar with document throughput (docs/sec), elapsed seconds, and ETA.
  • Streaming Terminal Console: Live output logs color-coded by severity (INFO, SUCCESS, WARN, ERROR, DEBUG).
  • Log Controls: Search inside logs, filter by level, toggle auto-scroll, and export/download log file as .txt.
  • Job Lifecycle: Manages state across IDLE, QUEUED, RUNNING, COMPLETED, and FAILED.
📊 4. Validation & Perception Analytics
  • Interactive Entity Highlighter: Color-coded token badges over text for PERSON, ORG, GPE, EVENT, PRODUCT with confidence scores on hover.
  • Perception Polarity Gauge: Needle meter from -1.0 (Critical/Panic) to +1.0 (Favorable) with Subjectivity Index.
  • Affect Spectrum Radar: Breakdown of 6 emotions (Fear, Anger, Trust, Joy, Sadness, Surprise) with panic escalation alerts.
  • Executive 3-Bullet SITREP: Synthesized bullet-point briefs.
  • Human Validation: Approve, flag, or correct predictions.
  • Exporting: Enriched export to JSON and CSV.

3. Specialized Intelligence & Perception Features

🧪 Single-Text Real-Time Playground

An ad-hoc testing sandbox allowing analysts to paste any single intercept, breaking news bulletin, or raw social post. The active pipeline executes in ~200ms without initiating a full batch job, rendering entity tokens, polarity gauges, and emotional affect scores immediately.

🔌 Backend Architecture & API Spec Guide

To empower backend development, a dedicated configuration panel provides:

  • Dual Operation Modes: Switch instantly between Simulation Mode (in-browser offline mock database) and Live Backend API (points to http://localhost:8000).
  • Connection Health Ping: 1-click test button verifying backend and MongoDB availability.
  • REST Contract Documentation: Full schema specifications for datasets, queries, and execution endpoints.
  • FastAPI + PyMongo Template: Copyable, battle-tested Python code.

6. Phase 2 Roadmap & Next Steps

Option A: Real Backend Implementation (FastAPI + PyMongo + Model Runtimes)

Launch local MongoDB service, run seed_mongodb.py to create live database collections, and implement real model inference in Python (using spaCy for entities and Transformers / VADER for perception). Switch frontend to "Live API" mode for end-to-end processing.

Option B: Real-Time WebSocket Streaming

Upgrade HTTP polling to WebSockets (ws://localhost:8000/ws/job/{id}) so token-by-token logs and inference progress stream directly into the dashboard console with zero latency.

Option C: Advanced Perception & Entity Analytics

Add temporal perception tracking (sentiment shift across dates) and an interactive Entity Relationship Graph visualizing co-occurrence networks between geopolitical actors, organizations, and targets.

Option D: Docker Containerization

Create a docker-compose.yml file orchestrating the React Frontend, FastAPI Backend, and MongoDB container with a single command: docker compose up.
